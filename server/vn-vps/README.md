# VN VPS Shadowsocks-rust deployment

**Template only** — no server has been deployed. Need Ubuntu/Linux VPS in Vietnam with Docker Compose and accessible TCP+UDP 8388.

1. Copy `config.example.json` to `config.json`; replace placeholder with a unique secret generated by `openssl rand -hex 32`. Run `chmod 600 config.json`.
2. Run `docker compose up -d`, then `docker compose ps` and `docker compose logs --tail 40`.
3. Permit TCP/UDP 8388 on cloud + OS firewalls and restrict SSH access.
4. In Shadowrocket, add Shadowsocks node with your public IP, port 8388, `chacha20-ietf-poly1305`, and the secret.
5. Import `build/vn-full.conf`, select that node, select Global Routing **Config**, then check `https://ipinfo.io` and DNS/IPv6.
6. Stop server via `docker compose down`. VPS rental charges remain until deprovisioned.

Home server requires a reachable public IP / port forward; CGNAT may prevent this. Tailscale exit node is an alternative but may conflict with Shadowrocket packet tunnel on iOS.
